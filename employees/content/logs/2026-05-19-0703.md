## アカウント設定
- **キャラクター：** 現役大学生・個人事業主
- **実績：** 物販・制作の個人事業で累計売上1000万円超。ただし256万円達成翌月に売上ゼロを経験
- **テーマ：** AI × 副業 × X運用 × 事業
- **フォロワー：** 10人（成長期・運用開始から日が浅い）
- **収益化状況：** noteもXもまだ収益ゼロ。個人事業の売上のみ
- **スタンス：** 成功談だけでなく失敗も全部さらす

## ■ 通常投稿（10本）

---

### 投稿①【失敗開示型｜140文字以内】

```
売上256万円の翌月、売上がゼロになった。

本当に、ゼロ。

あの絶望感、今でも覚えてる。
調子に乗ってた自分への罰だと思った。

でもそこで気づいた。
再現性のない売上は、ただのまぐれだって。

今は仕組みで売れる状態を作りに行ってる。
失敗した人間の話の方が、役に立つかもしれないから全部話す。
```
*文字数：約140字 ／ 型：失敗開示＋決意表明*

---

### 投稿②【FOMO型｜200〜350文字】

```
AIを副業に使っている人の中に、
決定的に「使い方が間違っている人」がいる。

「ChatGPTで文章作って投稿してます」
それ、作業の自動化じゃなくて、思考の放棄です。

AIに任せていい部分と、
自分の言葉でやらないといけない部分がある。

フックは自分の感情から作る。
構成はAIに手伝わせる。
数字と体験は自分だけが持っている。

この3つを混ぜると、
読まれるコンテンツになる。

ツールに頼りすぎた投稿は、
読んでいて「薄い」と感じる。
その薄さ、フォロワーにはバレてる。

保存しないと損します。
```
*文字数：約260字 ／ 型：指摘＋解決策＋CTA*

### 投稿④【数字型｜200〜350文字】

```

「うまい文章」じゃなくて「リアルな体験」が必要だった。

今の自分のフォロワーは10人。
それでも毎日投稿する理由がある。

・投稿を続けることで思考が整理される
・自分の言語化能力が明らかに上がる
・100日後の自分への仕込みになる

フォロワー数は結果。
でも過程で得るものの方がでかい。

0から始める人間にしか語れないことがある。
それをこのアカウントで全部残していく。

フォローで毎日学べます。
```
*文字数：約235字 ／ 型：体験＋箇条書き＋CTA*

### 投稿⑤【否定・間違い指摘型｜140文字以内】

```
note、全然売れない人に

タイトルです。

「〇〇について」「私の経験談」
```

### 投稿⑥【断言型｜200〜350文字】

```
副業を始める人が最初に間違えること、正直に言います。

「スキルを身につけてから売ろう」

これ、間違いです。

スキルは売りながら上がる。
完璧になってから売ろうとする人は、
永遠に売れない。

自分も最初は「まだ早い」と思ってた。
でも最初の1件を受けたとき、
強制的にレベルが3段階上がった。

お客さんがいる緊張感は、
自習では絶対に再現できない。

売上を作るのは、準備じゃなくて行動。
準備期間が長い人ほど、最初の一歩が怖くなる。

今すぐできる小さな一歩を踏み出してほしい。
```
*文字数：約270字 ／ 型：否定＋体験談＋行動促進*

---

### 投稿⑦【AI活用実践型｜200〜350文字】

```
AIをビジネスに活用して変わったこと、具体的に話します。

【Before】
・記事1本：3〜4時間
・SNS投稿考える：1時間
・返信文考える：30分

【After AI導入】
・記事の構成：15分
・投稿の方向性整理：10分
・返信の下書き：5分

浮いた時間で何をしてるか。
「考える時間」に使ってる。

AIに任せたのは作業。
自分がやるのは判断と体験の言語化。

この使い分けができるかどうかで、
AIを使っている人の中でも差がつく。

道具の使い方を知ってるだけで、
同じ時間で3倍のアウトプットが出せる。

保存しないと損します。
```
*文字数：約280字 ／ 型：ビフォーアフター＋本質＋CTA*
