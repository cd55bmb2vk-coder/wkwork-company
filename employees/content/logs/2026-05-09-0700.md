# 通常投稿 10本

---

## 投稿①【共感×フック強め｜100〜140字】

```
大学生なのに売上256万達成した翌月、売上ゼロになった。

理由は「次の月の仕込みを何もしてなかった」から。

伸びた実感に酔って、動きが止まってた。

事業って、うまくいってる時こそ一番怖い。
```

**狙い：** 失敗×本音型。「自分も同じ」という共感を最大化。リサーチで判明した「本音成分が信頼を生む」法則を適用。

---

## 投稿②【ノウハウ型｜200〜350字】

```
AIを使い始めて、1日の作業時間が3時間減った。

具体的にやったこと3つ：

① note記事の構成をChatGPTに出させる
→ ゼロから考える時間ゼロ。叩き台が30秒でできる。

② X投稿のフックを5案AIに出させて、1番刺さるものを選ぶ
→ 「自分の感覚」に頼らなくなった。

③ リサーチはPerplexityに丸投げ
→ 情報収集が30分→5分に。

AIを「全部やらせるもの」と思ってた時期は使い方が下手だった。

正解は「判断だけ自分でやる」。

作業を減らして、思考に時間を使う。これが今一番大事だと思ってる。

保存しないと損します
```

**狙い：** 具体手順×自分の変化を組み合わせた保存誘発型。「30分→5分」の数値コントラストを活用。

---

## 投稿③【警告型フック｜100〜140字】

```
フォロワー10人でもXで発信し続ける理由、聞かれた。

「誰にも見られてないのに意味あるの？」って。

逆に聞きたい。

フォロワー0の人間が発信しない理由って、何？

始めないと始まらないは、本当のことだよ。
```

**狙い：** 問いかけ型で反論を先回りし、共感とリプライを引き出す。フォロワー少ない層への刺さりを最大化。

---

## 投稿④【数字×逆説型｜200〜350字】

```
大学生で事業をやってる人に正直に言う。

「副業で月5万」より「事業で月0万の月」の方が、学びが100倍多い。

僕の場合、売上256万の翌月に売上ゼロを経験した。

あの月に気づいたこと：
・売上は「仕込み」の結果であって、今月の行動の結果じゃない
・うまくいってる月ほど、次の仕込みに本気になるべき
・失敗って、成功より再現性がある（なぜ失敗したかは説明できる）

失敗を経験した人間の話の方が、絶対に信用できる。

成功談だけ話す人を、僕はあまり信用してない。

フォローで毎日学べます
```

**狙い：** 逆説型タイトル＋失敗から得た具体インサイトで差別化。「成功談だけの人を信用しない」という主張がフォロー動機を生む。

---

## 投稿⑤【属性×実績型｜100〜140字】

```
現役大学生、事業売上1000万超えた。

でも今のXフォロワーは10人。

どっちがすごいかで言えば多分前者だけど、どっちが恥ずかしいかで言っても前者だ。

発信、ちゃんとやる。
```

**狙い：** 自己開示×自虐で親近感と注目を同時獲得。「売上1000万×フォロワー10人」のギャップが興味を引く。

---

## 投稿⑥【再現性×ノウハウ型｜200〜350字】

```
noteで稼ぐのに、フォロワーは関係ないと思ってる。

理由は3つ：

① Googleからnoteに流入するルートがある
→ SEOで検索流入が取れれば、フォロワー0でも読まれる。

② 「誰が書いたか」より「何が書いてあるか」で売れる
→ 無名でも解決策が明確なら買われる。

③ noteは「販売ページ」を無料で作れるプラットフォーム
→ 他の媒体よりハードルが低い。

今の僕はまだnoteでは収益ゼロ。

だからこそ、ゼロから試している人の視点で正直に書く。

保存しないと損します
```

**狙い：** 「自分もまだゼロ」という正直さが信頼になる。ノウハウ型＋本音の複合構造。

---

## 投稿⑦【問いかけ型｜100〜140字】

```
「AIって結局使いこなせてる？」

完璧を待ってると、永遠に始まらないから。
```

**狙い：** 自問自答スタイルで読者を内省に引き込む。「完璧を待つな」というメッセージで共感を誘発。

---

## 投稿⑧【暴露型フック｜200〜350字】

```
X運用で「伸びない」って嘆いてる人に正直に言う。

たぶんフックがダメです。

1文目で読む気がなくなると、続きは読まれない。

伸びてる投稿の1文目のパターン、3つだけ覚えて：

①「〇〇な人、正直に言います」→ 告白型
②「〇〇をやったら、△△になった」→ 体験型  
③「なぜ〇〇なのか、理由を知ってますか？」→ 問いかけ型

この3パターンを使うだけで、反応が変わった。

X始めて3ヶ月の自分でも、これだけは実証済み。

フォローで毎日学べます
```

**狙い：** 「あなたの問題はここ」という直接指摘型。リサーチで判明したフックパターンを実践コンテンツとして転換。

```
大学1年の夏、初めて自分で稼いだのは3,500円だった。

フリマアプリで古着を売った。

「これ、もっとやれる」と思った。

それから物販を本格的に始めて、気づいたら年商1000万を超えてた。

でも正直、一人でやってることの限界もわかった。

だから今、AIを使って一人の生産性を上げることを研究してる。

フォロワーは10人。

```

**狙い：** 原点ストーリー×現在地×目的の3点を自然につなげる自己紹介型。フォロワー0からのフォロー動機を生む。

## 投稿⑩【データ×本音型｜100〜140字】

```
事業をやってる大学生が、なぜXで発信するか。

理由は単純で「信頼の先払い」だと思ってる。

フォロワー0のうちから発信した人と、フォロワーが増えてから発信した人では、最終的な信頼量が全然違う。

```

**狙い：** 「発信の目的」を論理的に言語化することで、読者の発信意欲を刺激し共感を獲得。
