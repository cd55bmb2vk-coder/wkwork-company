## 通常投稿（10本）

---

### 投稿①【失敗告白フック】

```
大学生で月256万を達成した翌月、売上はゼロ円でした。

稼ぎ方は知ってた。でも続け方を知らなかった。

1つの販路に依存して、ひと晩でゼロになった。

この失敗が、今のAI×副業への転換点です。

同じ道を歩んでほしくないから、全部話します。
```

**文字数目安：** 110字
**フック：** 数字＋告白型
**リサーチ根拠：** ビフォーアフター数字がいちばんRT・保存を生む法則に基づく

---

### 投稿②【AI活用で時間が変わった話】

```
去年まで1日8時間作業してた。今は3時間で終わる。
変えたのはAIの使い方だけ。

①投稿の下書きをChatGPTに任せた
→「書く」から「直す」に変えたら速度が3倍に

②返信テンプレをClaudeで作った
→会話量が増えてフォロワーと繋がりやすくなった

③リサーチをAIに外注した
→「何を投稿するか」で悩む時間がゼロになった

「時間がない」は言い訳じゃなくて、やり方を知らなかっただけだとわかった。

フォローで毎日このレベルの話をします。
```

**文字数目安：** 220字
**フック：** 時間変化の数字比較（8時間→3時間）
**リサーチ根拠：** 「変えただけで〇倍」という再現性フックが最も保存率を上げる

---

### 投稿③【フォロワー10人でも続ける理由】

```
フォロワーが10人でも毎日投稿する。

1万人に刺さる言葉は、1人に刺さる言葉の延長線上にある。

今は練習期間。うまくなる過程を全部見せます。

保存しとくと後で「あの頃から見てた」って言えます。

**文字数目安：** 108字
**フック：** 逆張り（フォロワー少い＝負けじゃないという視点）
**リサーチ根拠：** 成長記録型コンテンツはフォロワーの共感と応援を引き出す

---

### 投稿④【256万→ゼロになった理由 全公開】

```

**フック：** 暴露型（正直に全公開）
**リサーチ根拠：** 箇条書き3点＋正直系フックが信頼獲得の最速パターン

### 投稿⑤【AIでネタ切れが消えた話】

```
AIを使い始めてから、投稿のネタ切れが消えた。

### 投稿⑥【大学生事業の孤独】

```
大学生で事業をやってて、いちばんきつかったのは「孤独」でした。

相談できる人がいない。友達は就活の話をしてる。親には「勉強しろ」と言われる。

でも諦めなかった理由は1つ。「やめた後悔よりも、続けた失敗の方がマシ」だと思えたから。

実際にやらかした失敗。
・仕入れミスで10万損した
・売れると思った商品が全滅
・256万稼いだ翌月にゼロ円

それでも続けてる。今はAIを武器に、X×noteで次の挑戦をしてる。

大学生でも事業はできる。でも誰も教えてくれないことが多すぎる。だからここで全部話します。
```

**文字数目安：** 265字
**フック：** 孤独への共感
**リサーチ根拠：** 「自分のことだ」と思わせる二人称的な感情描写が拡散を生む

### 投稿⑧【noteを始めた理由と目標】

```
noteを始めたのは「収益化できるから」じゃなくて、「自分が欲しかった情報がなかったから」です。

大学生で事業をやってると知りたい情報がない。
・学生起業の税金どうするの？
・物販とAIの組み合わせ方は？
・X運用はどのフェーズから収益化できる？

こういうリアルな情報がほぼ見当たらなかった。だから自分で書くことにした。

今はまだ収益ゼロ。でも3ヶ月後に有料記事で月3万の収益を作る。それが今の目標。

自分のリアルな挑戦を全部ここで公開します。フォローして一緒に見届けてください。
```

**文字数目安：** 255字
**フック：** 「〇〇のためじゃない」否定フック＋本音告白
**リサーチ根拠：** 具体的な目標数値（月3万）が信頼性と期待感を同時に高める

```
