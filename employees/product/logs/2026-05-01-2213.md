## 売上256万円の翌月にゼロになった話

大学2年の秋のことだ。

月の売上が256万円を超えた月があった。
物販と制作の個人事業を並行して、
初めて「これは本物になるかもしれない」と思った。

でも翌月、売上はほぼゼロになった。

理由はシンプルだった。
売上の8割が「1つの取引先」に依存していたからだ。

その取引先が、突然撤退を決めた。
連絡が来たのは夜の11時。
翌朝には取引を停止されていた。

256万円の売上は、砂の城だった。
土台がなかった。

この失敗は、今でも自分の中で生きている。
事業の話をするとき、必ずここに戻る。

**「依存は死ぬ。分散が命。」**

これが最初の学びだった。

## なぜ「一点集中」が危険なのか

副業や事業を始めると、最初は「選択と集中」という言葉を聞く。
実際、集中は大事だ。

でも「依存」と「集中」は別物だ。

- 集中：1つの強みを磨くこと
- 依存：1つの収益源だけに頼ること

この2つを混同すると、ある日突然すべてが崩れる。

自分の場合は販路の依存だった。
でも他にも危険なパターンがある。

1つ目は「プラットフォーム依存」だ。
SNSのアカウントが凍結されたら収入がゼロになるケース。

2つ目は「スキル依存」だ。
1つのスキルだけで稼いでいて、そのスキルが市場で不要になるケース。

3つ目は「時間依存」だ。
自分が動いた時間だけ収入が発生する構造。
体が動かなければ収入も止まる。

大学生の副業は、この3つのリスクにさらされやすい。

だから最初から「分散できる設計」で動くことが重要なんだ。

## AIと出会って変わった3つのこと

売上ゼロの翌月から、AIの勉強を始めた。

きっかけは小さかった。
友達に「ChatGPT、ちゃんと使えてる？」と聞かれたことだ。

正直に言うと、使えていなかった。
「便利なメモ帳」くらいの認識しかなかった。

でも、本気で向き合い始めてから3つのことが変わった。

**変化①：作業時間が3分の1になった**

物販の商品説明文を書くのに、1本30分かかっていた。
ChatGPTで下書きを作り、自分で手直しするスタイルに変えたら、5分で終わるようになった。

月に100本書いていたとすると、
以前は50時間かかっていたものが、8時間で済む。

浮いた42時間で、次の事業を考えられるようになった。

**変化②：「考える仕事」に集中できるようになった**

AIが得意なのは「決まった型の処理」だ。
文章生成、情報整理、アイデア出しなど。

逆に人間にしかできないのは、
「どちらの方向に進むか」という判断だ。

AIを使うと、自動的に「自分の役割」が上位概念にシフトする。
これが事業の成長速度を上げる。

**変化③：発信が続くようになった**

Xでの発信を毎日続けるのは難しかった。
ネタ切れ、文章の完成度への不安、時間不足。

でもAIを使うと「投稿の下書き」を30秒で作れる。
あとは自分の言葉に書き直すだけ。

発信が続くと、フォロワーが少しずつ増える。
フォロワーが増えると、事業の告知が届く範囲が広がる。

この好循環を、AIが作ってくれた。

## 大学生が副業×事業を両立する具体的な方法

大学生の最大のリソースは「時間」じゃない。
「信用コスト の低さ」だ。

失敗しても「まだ学生だから」で許される。
リスクを取りやすい期間が、今だ。

この期間を最大限に使うために、以下の構造を推奨する。

**▼ 稼ぐ構造の設計図**

```
[Layer 1] 即金収入：物販・受託制作・クラウドソーシング
    ↓
[Layer 2] 資産形成：X発信→フォロワー→note販売
    ↓
[Layer 3] 自動収入：コンテンツ販売・デジタル商品の積み上げ
```

最初はLayer 1だけでいい。
現金を稼ぎながら、Layer 2に時間を少しずつ使う。

Layer 2が育つと、Layer 3への道が開ける。

これは1日で完成する話じゃない。
でも「設計図がある状態」と「ない状態」では、
1年後の結果が全然違う。

自分は設計図なしで動いて、売上ゼロを経験した。
設計図を持ってから、ようやく安定してきた。

「時間がない」という人でも再現できる構成を紹介する。

```

```

これだけで「毎日発信できる人」になれる。

**昼15分：事業の仕込み**

```
1. 商品説明文・メール・資料などをAIで下書き作成
2. 手直しして完成させる
3. 次のタスクをAIに整理してもらう
```

**夜5分：Xのリプ・いいね巡回**

```
1. 副業・AI・大学生系の投稿にいいね
2. 気になった投稿にリプ
3. フォロワーの反応を確認
```

合計30分。
これを90日続けると、世界が変わる。

数字で言うと、
90日×30分＝45時間の投資で、
発信の習慣と最初のフォロワーと最初の収益の種が生まれる。

## 失敗から学んだ「稼げる人」と「稼げない人」の差

色々な人を見てきて、差は1つだと気づいた。

**「出しながら完成させるか、完成してから出すか」の違いだ。**

稼げない人の思考：
→ 「もっと完璧にしてから出そう」
→ 出さないまま時間が過ぎる
→ 「やっぱり自分には無理かも」と諦める

稼げる人の思考：
→ 「まず出してみて、反応を見てから直そう」
→ 毎日出す
→ 少しずつ反応が増える
→ 自信がつく

自分も最初は前者だった。
完璧な投稿を作ろうとして、週1本しか出せなかった。

今は毎日出す。
完璧じゃないものが9割だ。
でも毎日出すことで、フォロワーが少しずつ増えている。

量は質を生む。
まず出すことが全ての始まりだ。

もう1つ大事なことがある。

「失敗を隠さないこと」だ。

成功談しか発信しないアカウントは、
実は読者に信用されにくい。

人は「自分と同じ失敗をした人の話」に一番共感する。

自分が売上ゼロを経験したことを正直に書いたら、
「自分だけじゃなかったんだ」というリプが来るようになった。

失敗は最高のコンテンツだ。
